# nathan-haII.github.io

My personal portfolio site — built to showcase my projects and skills as a Computer Science student.

**Live site:** https://nathan-haii.github.io <!-- update once GitHub Pages is enabled -->

## About

I'm a Computer Science student at McMaster University interested in computer vision, anomaly detection, and data science. This site is a single-page portfolio covering my background, skills, and featured projects.

## Built with

- HTML5 / CSS3 (no framework, no build step)
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), and [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts

The whole site is one self-contained `index.html` file — no dependencies, no npm install, no build process.

## Running locally

Clone the repo and open the file directly in a browser:

```bash
git clone https://github.com/nathan-haII/nathan-haII.github.io.git
cd nathan-haII.github.io
open index.html   # or just double-click it
```

## Deployment

This repo is deployed with [GitHub Pages](https://pages.github.com/):

1. Settings → Pages → Source: Deploy from a branch
2. Branch: `main`, folder: `/root`
3. Site publishes automatically on every push to `main`
