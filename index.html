Blue Jays xwOBA tracker

Compares each Blue Jays hitter’s actual wOBA with the wOBA his batted balls suggest (xwOBA), tests whether that gap carries over to the next season, and checks which stat predicts next season’s wOBA best. The pipeline downloads Baseball Savant and MLB Stats API data, cleans it, loads it into a SQLite database, uses SQL to pair each hitter’s season with the next, and scores the models on a held-out season. A Shiny app lets you explore every hitter.

Across 2,422 hitter-season pairs, the gap carried over with a slope of 0.22 and an R² of 0.05, so most of it is noise. A blend of last season’s wOBA and xwOBA had the lowest error when tested on the 2025 to 2026 seasons.

Built with R, SQL (SQLite), the tidyverse and Shiny.

Document Scanner

A Python command-line tool that turns a photo of a document into a clean, flat, black-and-white scan. It finds the document’s edges, corrects the perspective so the page looks squared off, then applies adaptive thresholding.

Built with Python, OpenCV, NumPy, scikit-image and imutils.

Ontario License Plate Scanner

A classical computer vision pipeline that finds and reads Ontario license plates in photos, with no deep learning. It locates the plate with edge detection and connected components, separates the characters with adaptive thresholding, and classifies each 20×20 crop with a support vector classifier. A final step uses the plate format of four letters followed by three digits to fix confusable characters such as 0 and O, or 5 and S.

Built with Python, scikit-image, scikit-learn, NumPy and Matplotlib.
